# EARTH JUKEBOX

**Hear the Planet. Understand Its Pulse.**

An audio-first scientific exploration platform that transforms NASA Earth observations into meaningful, evolving soundscapes.

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- React
- TypeScript
- Tone.js
- Web Audio API

## Project Structure

- `data/raw/` - Original NASA datasets
- `data/processed/` - Standardized datasets
- `data/metadata/` - Scientific dataset metadata
- `processing/` - Scientific data processing scripts
- `assets/nasa/` - NASA visual assets
- `docs/` - Scientific documentation
